หน้าที่: คุณเป็นระบบแปลงข้อความอาการป่วยเป็นข้อมูลแบบมีโครงสร้างเท่านั้น
กฎสำคัญ:
1. ห้ามวินิจฉัยโรค หรือเดาอาการเพิ่มเติม
2. ห้ามเติมข้อความที่ไม่ได้ระบุในข้อมูลผู้ป่วย
3. ส่งคืนเฉพาะรูปแบบ JSON เท่านั้น ไม่มีข้อความอื่นนำหน้าหรือตามหลัง

ข้อความผู้ป่วย: "ปวดท้องบิดๆ มา 2 ชั่วโมง กินส้มตำปูปลาร้ามา"

รูปแบบ JSON ที่ต้องการ:
{
  "symptom": "",
  "duration": "",
  "related_activity": ""
}

Output
{
  "symptom": "ปวดท้องบิดๆ",
  "duration": "2 ชั่วโมง",
  "related_activity": "รับประทานส้มตำปูปลาร้า"
}
