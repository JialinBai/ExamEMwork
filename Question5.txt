ผมจะเก็บไฟล์ X-Ray ต้นฉบับไว้ใน Object Storage เช่น MinIO หรือ AWS S3 เพราะรองรับไฟล์ขนาดใหญ่และสามารถขยายระบบได้ง่าย 

ส่วนการแสดงผลบนมือถือจะสร้างภาพขนาดย่อและไฟล์ที่บีบอัดไว้ล่วงหน้าเพื่อลดเวลาในการโหลดเพื่อให้แพทย์เปิดดูผลตรวจได้รวดเร็วขึ้น จะใช้ Internal CDN หรือ Cache Server ภายในโรงพยาบาล และใช้ Progressive Loading เพื่อให้เห็นภาพก่อนแล้วค่อยโหลดรายละเอียดเพิ่มเติมเมื่อจำเป็น

ในด้าน PDPA ข้อมูลจะถูกเข้ารหัสทั้งขณะจัดเก็บและขณะส่งผ่านเครือข่าย มีการตรวจสอบสิทธิ์ผู้ใช้งานก่อนเข้าถึงข้อมูลทุกครั้ง และบันทึกประวัติการเข้าถึงเพื่อให้สามารถตรวจสอบย้อนหลังได้หากเกิดปัญหา
